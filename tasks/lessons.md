# Delivery lessons

## 9 September — install before expanding the release scope

The founder explicitly asked to install Bento immediately after an update about Android backup work. Installed tooling must become available and visibly connected before adjacent improvements delay that request. Treat later product work as a separate increment with honest evidence, and answer status questions immediately. Apple Books is the EPUB quality floor; recording that reference does not establish parity.

## 9 September — moving controls changes their interaction boundaries

Menus, drawers and sticky headers change where controls can be reached. Verify actual pointer hit targets and keyboard focus after scrolling and reopening dialogs. Update workflow tests to navigate the visible controls, retaining source-byte, saved-work and failure assertions. Never count a locator click as proof that the intended control received it.

## 9 September — own the professional document interface

The founder asked where the actual PDF Expert parity UI was after seeing Bento. A tool catalog and a redirect are not the requested JETT workspace. Build direct JETT interactions over the verified engines, demonstrate the actual user journey in our interface, and never substitute toolkit availability for product parity.
