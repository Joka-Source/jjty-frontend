## Open questions

1. **Upstream port required for `jt-speech`.** The vendored package has three modified files and no added/removed files. Relative to sibling `main`, the vendored copy contains 24 lines not upstream and lacks 2 upstream lines:
   - `lexicon.js`: adds the `document.return` intent with `take me back`, `where was i`, and `go back to` triggers at threshold `0.9` (6 vendored-only lines).
   - `segmenter.js`: parses an unnamed return or a named `go back to <document>` command (13 vendored-only lines).
   - `types.d.ts`: adds `document.return`, `ReturnDocumentArgs`, and the union member (5 vendored-only lines, replacing 2 upstream lines).

   Exact diff summary:

   ```text
   vendor/jt-speech/lexicon.js: 0 upstream-only lines, 6 vendored-only lines
   vendor/jt-speech/segmenter.js: 0 upstream-only lines, 13 vendored-only lines
   vendor/jt-speech/types.d.ts: 2 upstream-only lines, 5 vendored-only lines
   3 files changed; vendored delta is 24 insertions and 2 deletions relative to upstream
   ```

   The amendment forbids modifying `jt-speech`, so this package must remain vendored until a separate upstream-port order is dispatched.

2. **The browser tier cannot be verified green in this managed sandbox.** All 60 non-browser tests and both parity cases pass, but all 13 browser cases abort while launching `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`. No product assertion runs in those cases. Re-run the exact full command from an execution context allowed to spawn Chrome.

3. **Commit blocked by the linked-worktree Git metadata permission.** The worktree's index is under the read-only path `/Users/apple/projects/jt-web/.git/worktrees/F-02-web-vendor/index`. The actual attempted indexed deletion failed verbatim:

   ```text
   fatal: Unable to create '/Users/apple/projects/jt-web/.git/worktrees/F-02-web-vendor/index.lock': Operation not permitted
   ```

   The judge or a local shell with write access to that Git metadata must run `git add -A && git commit` on `wo/f-02-web-vendor`. No push is required or authorized.

4. **Nested-worktree link reporting.** The committed manifest and lock use the canonical `file:../…` layout, and a clean simulated canonical sibling layout passed both `npm ci` and `npm ls --depth=0`. In this deeper worktree, the postinstall resolver points generated links at `/Users/apple/projects`, so `npm ls` reports those links as not matching the literal `../` spec even though the build and tests consume the intended repositories. That mismatch disappears after merge into the canonical `/Users/apple/projects/jt-web` checkout.
