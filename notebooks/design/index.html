Open workspace

Notebook screens and states

This is the implemented interaction contract, not an exhaustive Goodnotes inventory or a claim that every state has been visually verified. Actions below belong to the current browser workspace.

Verified journeys: library, creation, editor, page menus, export/import persistence, settings, typed voice matching and guide navigation. Still unverified: physical microphone, native pen behavior, cross-platform rendering, complete visual coverage of every error state. Water response is CSS motion; native Apple materials and physical simulation are not implemented.
