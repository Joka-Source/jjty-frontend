## Visual decision

Celadon desk `#e8efe5`, paper `#fafbf6`, ink `#253d50`, cobalt selection `#365ccd`, pale selection `#e5eafb`, plum attention `#785f77`. Dark chrome uses the existing slate palette; PDF paper retains source fidelity. Palatino remains the document title's quiet editorial identity; Avenir/system sans handles controls at 13–16 px. The page is the central object, not another card. Compact document header, broad inset work surface, subtle paper edge, one bottom tool dock. Reading is default. Side sheet opens only for notes, page text, export or precision entry. Controls have 44 px minimum touch targets and labels; hover is never required. Motion only answers tool/sheet/activity state changes, 160–200 ms, reduced-motion supported.

## Build order

1. Finish current native before inspection and preserve screenshots. No feature additions before this contract.
2. Replace editor composition: compact file header, page stage and persistent navigation; remove duplicated toolbar/always-open notes.
3. Implement one contextual dock and panel controller; preserve semantic command dispatch and existing engines.
4. Add direct text targeting with precision fallback, pen settings, enabled-state undo, and last-page continuity.
5. Integrate actual activity state into compact chrome, tighten save/export copy and panel states. No beta/provisional labels in working editor.
6. Verify rendered phone/desktop/light/dark plus Android before/after, then underlying source/annotation/recovery checks and full required suite. Fix failures before final provenance receipt and push.

Broader unsupported AI, submissions and certified signing are outside this working editor. No reference parity or native iOS integration is claimed by this contract. Acceptance cells above are tests to execute, not green receipts.

Native before review additionally found rotation returning to Welcome and losing editor context (`08-landscape-settled.png`). Acceptance: portrait → landscape → portrait retains current document, page and draft input/marks. Native-only owner implements this alongside the frontend workspace after this table.
